# Examples

Original demonstrations of the stage-grid-poster grammar. Each uses the stage-artifact-grid system: one full-bleed field, one dominant centered artifact, a micro header row, and a fixed three-column footer information grid.

- `example-meridian-earnings.svg` — cobalt stage, orbit artifact, standard earnings-call footer grid.
- `example-side-b-square.svg` — violet stage, display type as artifact, square carrier adaptation.
- `example-quiet-paper.svg` — paper stage, contained geometric artifact, quiet announcement.
- `example-mono-show.svg` — deep black stage, high-contrast silhouette artifact, show announcement.
